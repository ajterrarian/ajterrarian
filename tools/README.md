# profile asset generator

Every SVG in `../assets` is generated by these scripts. Nothing runs at page-view time — the SVGs
are committed and served straight from the repo.

## Look

Cyan (`#5AD8FF`) on true black, one committed palette in `THEMES` (`common.py`). There is
deliberately **no light variant**: the panels stay dark in both GitHub themes, so they read as
one surface rather than two. Display type is JetBrains Mono ExtraBold with a bloom pass behind
it; small text gets positive tracking, per Apple's typography guidance.

## Why the text is outlined

GitHub proxies README images through camo and renders them in SVG secure static mode, so an
`@font-face` pointing at a font CDN never loads. The scripts outline every glyph to a `<path>`
with fontTools instead, which is why the banner keeps JetBrains Mono on every machine.

## Build

```
python3 -m venv venv && ./venv/bin/pip install fonttools

curl -sL -o jbm.zip https://github.com/JetBrains/JetBrainsMono/releases/download/v2.304/JetBrainsMono-2.304.zip
unzip -q jbm.zip -d fonts
curl -sL -o satoshi.zip "https://api.fontshare.com/v2/fonts/download/satoshi"
unzip -q satoshi.zip -d fonts/satoshi

./venv/bin/python banner.py     # assets/banner.svg
./venv/bin/python panels.py     # assets/stack.svg
./venv/bin/python badges.py     # assets/badge-{email,linkedin,github}.svg
```

| File | Role |
| :--- | :--- |
| `typo.py` | text → SVG path outlines |
| `common.py` | palette, text helper, and the rounded card `surface()` |
| `banner.py` | the header banner — edit `NAME`, `EYEBROW`, `SUB` |
| `panels.py` | the stack panel — edit `GROUPS` |
| `badges.py` | contact pills — add to `BADGES` to make a new one |

Satoshi is still loaded in `common.py` (`BOLD`, `MED`, `REG`) if you ever want a non-mono display
face; nothing currently uses it.
